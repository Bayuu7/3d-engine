# 3D Engine + Web Frontend (Minimal Working Implementation)

This repository contains a modular 3D engine scaffold with a web-based editor frontend.
- Engine: Core loop, clock, global state, event bus, math (Vector3, Matrix4), scene graph, input manager, WebGL2 renderer stub.
- Frontend: Toolbar, hierarchy, inspector, gizmo overlay, integrated with the engine.

Run:
1. npm install
2. npm run dev
3. Open http://localhost:5173

Expand by implementing additional subsystems (physics, audio, networking) in their designated folders. Placeholder files include extensive comments about intended functionality and integration points.
